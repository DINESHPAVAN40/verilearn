# Contributing to VeriLearn

Thank you for your interest in contributing to VeriLearn! We welcome contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/verilearn.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Set up environment: `npm install && npm run dev`

## Development Guidelines

### Code Style
- Use TypeScript for type safety
- Follow ESLint configuration
- Use Prettier for formatting
- Write meaningful commit messages

### Components
- Create reusable components in `/components`
- Use Tailwind CSS for styling
- Add Framer Motion for animations
- Document props and usage

### Testing
- Test features locally before submitting PR
- Test on both desktop and mobile
- Check dark/light mode compatibility

### Pull Request Process

1. Ensure your code follows the style guide
2. Write a clear PR description
3. Link related issues
4. Wait for code review
5. Address feedback
6. Get approval and merge

## Reporting Bugs

1. Check if bug is already reported
2. Include clear title and description
3. Provide steps to reproduce
4. Include screenshots/videos if applicable
5. Mention browser and OS

## Feature Requests

1. Check existing issues first
2. Describe the feature clearly
3. Explain use case and benefits
4. Include mockups/examples if relevant

## Questions?

Open a discussion or reach out to maintainers.

Thank you for contributing! 🚀
