VeriLearn

A simple, browser-first learning platform for basic Verilog HDL lessons and examples.

Getting started (in the browser)

Open the examples below, copy them, or download the files to run locally with a simulator like Icarus Verilog.

How to use

  1. Click an example to view the Verilog source in the pane on the right.
  2. Use "Download" to save a .v file to your machine.
  3. To run simulations locally, install a Verilog simulator (e.g., Icarus Verilog) and run from terminal.

Host on GitHub Pages

Push this file to your repository root or to a /docs folder, then enable GitHub Pages in repository Settings → Pages → source: main branch / docs folder (or root). The site will be served as a static website.
