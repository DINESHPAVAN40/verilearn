# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅ Yes   |
| 1.x     | ❌ No    |

## Reporting a Vulnerability

If you discover a security vulnerability, please email security@verilearn.dev instead of using the issue tracker.

Please include:
- Description of vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

We will acknowledge receipt within 24 hours and provide an estimated timeline for a fix.

## Security Best Practices

### For Users
- Use strong, unique passwords
- Enable two-factor authentication (coming soon)
- Keep your browser and OS updated
- Don't share your account credentials

### For Developers
- Never commit sensitive credentials
- Use environment variables for secrets
- Review security rules before deployment
- Keep dependencies updated
- Report security issues responsibly

## Data Protection

- All data encrypted in transit (HTTPS)
- Firebase security rules protect user data
- No password stored in plain text
- Regular security audits planned

## Third-Party Services

- Firebase: Google Cloud certified
- Vercel: Enterprise-grade security
- Monaco Editor: Open source, regularly audited
