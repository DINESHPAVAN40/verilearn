# VeriLearn Deployment Guide\n\n## 🚀 Deploy to Vercel in 5 Minutes\n\nThis guide will help you deploy VeriLearn to Vercel (completely FREE).\n\n---\n\n## Step 1: Create Firebase Project (Free Tier)\n\n### A. Go to Firebase Console\n1. Open [Firebase Console](https://console.firebase.google.com/)\n2. Click **\"Create a project\"**\n3. Project name: `verilearn`\n4. Disable Google Analytics (optional)\n5. Click **\"Create project\"**\n\n### B. Enable Authentication\n1. Go to **Authentication** → **Get started**\n2. Click **Email/Password**\n3. Toggle **Enable**\n4. Click **Save**\n\n### C. Create Firestore Database\n1. Go to **Firestore Database**\n2. Click **Create database**\n3. Select **Start in test mode** (for development)\n4. Choose region closest to you\n5. Click **Create**\n\n### D. Setup Security Rules\n1. Go to **Firestore** → **Rules**\n2. Replace with this:\n\n```javascript\nrules_version = '2';\nservice cloud.firestore {\n  match /databases/{database}/documents {\n    // Users collection\n    match /users/{userId} {\n      allow read, write: if request.auth.uid == userId;\n    }\n    \n    // Projects collection\n    match /projects/{projectId} {\n      allow read, write: if request.auth.uid == resource.data.userId;\n      allow create: if request.auth.uid == request.resource.data.userId;\n    }\n  }\n}\n```\n\n3. Click **Publish**\n\n### E. Get Firebase Credentials\n1. Go to **Project Settings** → **General**\n2. Scroll to **Your apps** section\n3. Click **Web** icon (if not created)\n4. Copy all config values\n5. Keep this page open (you'll need these values)\n\n---\n\n## Step 2: Prepare Local Environment\n\n### A. Clone Repository\n```bash\ngit clone https://github.com/DINESHPAVAN40/verilearn.git\ncd verilearn\n```\n\n### B. Install Dependencies\n```bash\nnpm install\n```\n\n### C. Setup Environment Variables\n```bash\n# Copy template\ncp .env.example .env.local\n```\n\n### D. Edit `.env.local`\nPaste your Firebase credentials:\n```\nNEXT_PUBLIC_FIREBASE_API_KEY=your_value_here\nNEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_value_here\nNEXT_PUBLIC_FIREBASE_PROJECT_ID=your_value_here\nNEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_value_here\nNEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_value_here\nNEXT_PUBLIC_FIREBASE_APP_ID=your_value_here\nNEXT_PUBLIC_APP_URL=http://localhost:3000\n```\n\n### E. Test Locally\n```bash\nnpm run dev\n```\n\nVisit `http://localhost:3000` and test:\n- ✅ Sign up with email\n- ✅ Create a project\n- ✅ Save code\n- ✅ Load project\n\n---\n\n## Step 3: Deploy to Vercel\n\n### A. Push to GitHub\n```bash\ngit add .\ngit commit -m \"Ready for Vercel deployment\"\ngit push origin feature/complete-workspace\n```\n\n### B. Create Pull Request (Optional)\n1. Go to [Your Repo](https://github.com/DINESHPAVAN40/verilearn)\n2. Click **Pull requests** → **New pull request**\n3. Base: `main`, Compare: `feature/complete-workspace`\n4. Click **Create pull request**\n5. Click **Merge pull request**\n\n### C. Deploy on Vercel\n1. Go to [Vercel](https://vercel.com/)\n2. Sign in with GitHub\n3. Click **New Project**\n4. Select `verilearn` repository\n5. Click **Import**\n\n### D. Add Environment Variables\n1. In Vercel, go to **Settings** → **Environment Variables**\n2. Add each Firebase credential:\n   - Key: `NEXT_PUBLIC_FIREBASE_API_KEY`\n   - Value: Your API key\n   - Repeat for all values from Step 1.E\n\n### E. Deploy\n1. Click **Deploy**\n2. Wait 2-3 minutes\n3. ✅ Your app is live!\n\n---\n\n## 📊 Firebase Free Tier Limits\n\n| Feature | Free Tier | Enough For? |\n|---------|-----------|------------|\n| **Storage** | 1 GB | ✅ Yes |\n| **Reads/day** | 50,000 | ✅ Yes |\n| **Writes/day** | 20,000 | ✅ Yes |\n| **Deletes/day** | 20,000 | ✅ Yes |\n| **Connections** | 100 concurrent | ✅ Yes |\n| **Cost** | **Free** | ✅ Always |\n\n---\n\n## 🔐 Production Checklist\n\nBefore going live to many users:\n\n- [ ] Update Firebase rules from \"test mode\"\n- [ ] Enable reCAPTCHA for authentication\n- [ ] Setup backups\n- [ ] Monitor Firestore usage\n- [ ] Add custom domain (optional)\n- [ ] Enable HTTPS (automatic on Vercel)\n- [ ] Setup CI/CD pipeline\n- [ ] Add rate limiting\n- [ ] Setup error logging\n\n---\n\n## 🐛 Troubleshooting\n\n### Firebase Connection Error\n```\nError: Firebase config is incomplete\n```\n**Solution:** Verify all env vars are set correctly in `.env.local`\n\n### Firestore Quota Exceeded\n```\nError: Quota exceeded\n```\n**Solution:** Check Firestore usage in Firebase Console. Upgrade if needed.\n\n### Cannot Sign Up\n```\nError: User creation failed\n```\n**Solution:** Ensure Email/Password auth is enabled in Firebase Console\n\n### Build Fails on Vercel\n```\nBuild failed: Cannot find module\n```\n**Solution:** Run `npm install` locally and commit `package-lock.json`\n\n---\n\n## 📈 Monitoring & Scaling\n\n### Monitor Usage\n- Firebase Console → Dashboard\n- Vercel Dashboard → Analytics\n\n### Upgrade to Paid (If Needed)\n- Firebase: Pay as you go\n- Vercel: $20/month Pro plan\n\n### Scale the App\n- Split workspaces by tenant\n- Add caching layer\n- Optimize Firestore queries\n- Use CDN for assets\n\n---\n\n## 🎉 You're Done!\n\n✅ VeriLearn is now live on the internet!\n\n### Next Steps:\n1.
